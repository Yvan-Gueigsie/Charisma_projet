Suivi de personne

Caméra du téléphone → détection de personne → ESP32 en Bluetooth LE

Prêt. Connecte l’ESP32 puis démarre la caméra.

Position X : 0.000 Détection : Aucune Bluetooth : Déconnecté

X = -1 : personne à gauche ; X = 0 : personne au centre ; X = +1 : personne à droite. Sans personne détectée, la consigne envoyée est 0.

Le BLE Web nécessite un navigateur compatible (notamment Chrome sur Android) et une page HTTPS. Les UUID et le nom Bluetooth doivent correspondre au programme ESP32.
